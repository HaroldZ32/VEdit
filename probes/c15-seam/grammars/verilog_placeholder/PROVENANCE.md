# Provenance — verilog_placeholder grammar

- **Identity**: `verilog_placeholder`, authored inside this repository for the
  C15 seam probe. It is deliberately a *subset* of Verilog (module / net /
  assign / always / begin-end / small expressions); the contract for
  `r2-c15-probe` explicitly allows a minimal/placeholder Verilog-family grammar.
- **Licence**: MIT (see `LICENSE`), authored here, no third-party derivation.
- **Generated by**: tree-sitter CLI `0.27.1` (`tree-sitter generate`), which
  embeds `LANGUAGE_VERSION 15` into `src/parser.c`.
- **Files checked in**: `grammar.js` (source of truth), `src/parser.c`,
  `src/tree_sitter/*.h`, `queries/{highlights,folds,structure}.scm`, plus the
  generator side-products `src/grammar.json` / `src/node-types.json`.
- **sha256 of generated parser**: recorded in `evidence/r2-c15/00-pins.txt`.

The grammar is never referenced by the C++ interface or by the caller; only the
CMake configuration selects it (`-DSEAM_GRAMMAR=verilog_placeholder`).
