VEdit 0.4.0 是面向 Linux x86_64 的 Qt6 桌面版。

### 大工程与界面

- 启动时显示带呼吸渐变条的欢迎窗口。导入 filelist 后，VEdit 在后台准备模块目录，分批显示大型模块树。
- 停靠面板、工具栏和编辑标签增加拖动反馈。主要面板、标签和文件树支持按选中对象打开右键菜单，并支持减弱动效。

### 文件比较和 SVN

- 从 File 菜单或 Files 树打开两个文件，可用中间箭头双向应用差异块、撤销、分别保存。SVN 文件与修订复用同一窗口。
- 可以比较上一实际改动修订、任意两个修订，以及 BASE、HEAD 或指定修订与工作副本。取回历史内容后，显式保存才会写入磁盘。
- 新增或扩展 SVN 检出、变更列表、选择性提交、分支与合并、冲突解决、历史、补丁、多工作副本与已检出的目录型 externals。连续文件变更会合并刷新。

### SystemVerilog 导航

- 新配置的 Verilog/SystemVerilog 语义后端默认为 slang。显式 Verible 配置会保留。
- `Trace Driver`、`Trace Load` 可直接追踪写入端与读取端。`Show Driver Chain`、`Show Load Chain` 可沿不同实例展开并跳转源码。

### 使用与边界

下载 `VEdit-0.4.0-x86_64.AppImage` 和 `SHA256SUMS`，在同一目录执行 `sha256sum -c SHA256SUMS`。比较窗口支持每侧不超过 8 MiB、100,000 行的 UTF-8 文本。信号追踪基于已保存的设计，最多处理 2,000 个工程文件、32 层及 512 行结果。
