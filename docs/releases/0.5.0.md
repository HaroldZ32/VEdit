VEdit 0.5.0 增加了编辑器内的并排文件比对和 SVN 修订比对，并修复了导入 filelist 后的 Slang 实时分析。Linux x86_64 版提供 AppImage、`.tar.gz` 和 `.run`，三种格式运行同一 Qt6 应用。

### 文件比对与 SVN

- 从 `File → Compare Files…` 或文件树的 `Compare With…` 在当前分屏打开并排比对标签，保留语法高亮，并标出行内改动。可同步滚动，使用 `Alt+PageUp` 或 `Alt+PageDown` 跳转差异。
- 可编辑本地文件、向任一侧应用差异块、撤销并按侧保存。普通编辑器和比对视图共享同一可写文件的缓冲区，包括未保存的修改。关闭最后一个视图前可选择保存、丢弃或取消。
- 从 `File` 菜单将当前缓冲区与 SVN `BASE` 比对，或打开文件的 SVN 历史，比较所选修订、上一文件修订或工作副本。历史快照为只读。
- 打开较多文件时，可用鼠标滚轮或滚动条浏览标签。浏览不会切换当前文件，选中标签后会将它滚动到可见区域。

### HDL 实时分析

- 导入 filelist 后，Slang 实时诊断按工程文件集解析当前文件的直接子模块。修复了编辑后宏展开产生的实例或通过包含文件找到的子模块丢失上下文、误报找不到模块的问题。确实缺失的模块仍会报告。
- 导入 filelist 后，在 `Project` 面板添加或修改同名宏，可以覆盖原生 Slang 配置中的 `-D`，实时诊断随之更新。移除面板覆盖后恢复原有优先级，原生 `-U` 仍有效。

### 下载与启动

选择一种格式，并把同版本的 `SHA256SUMS` 放在下载目录。以 AppImage 为例，运行 `awk '$2 == "VEdit-0.5.0-x86_64.AppImage"' SHA256SUMS | sha256sum --check`，确认该文件显示 `OK`。校验其他格式时替换命令中的文件名。

| 下载文件 | 启动方式 |
|---|---|
| `VEdit-0.5.0-x86_64.AppImage` | `chmod +x VEdit-0.5.0-x86_64.AppImage` 后运行。没有 FUSE 时加 `--appimage-extract-and-run` |
| `vedit-0.5.0-linux-x86_64.tar.gz` | `tar -xzf vedit-0.5.0-linux-x86_64.tar.gz`，然后运行 `./vedit-0.5.0-linux-x86_64/AppRun` |
| `VEdit-0.5.0-x86_64.run` | `chmod +x VEdit-0.5.0-x86_64.run` 后运行，或用 `--extract DIR` 解到新目录供后续启动 |

### 已知限制

- 文件比对支持 UTF-8 文本，每侧最多 8 MiB 和 100,000 行。SVN 操作需要宿主机的 `svn`。
- 桌面改动的验收使用 X11/Xvfb，SVN 验收使用本地仓库。原生 Wayland 和远端 SVN 传输仍需单独验证。
- CentOS 7 容器检查覆盖 glibc 2.17 用户空间。CentOS 7 原生 3.10 内核需独立验证。
