VEdit 0.4.1 改进了文件夹会话、编辑体验和 HDL 工程导航。Linux x86_64 版提供 AppImage、`.tar.gz` 和 `.run`，三种格式运行同一 Qt6 应用。

### 桌面与编辑

- 文件夹保存各自的工程配置，支持最近文件夹和可选的启动恢复。切换文件夹时保留已打开的标签页和未保存内容。单独打开文件时，可以只在该文件范围内搜索。
- 搜索面板与查找替换共用历史记录。简化了文件树和窗格的常用操作，批量展开可以随时停止。
- `.f` 和 `.F` 编辑支持路径补全。Markdown 增加高亮，HDL 高亮改进了模块定义、例化和结构关键字的显示。
- 驱动和负载追踪显示每一跳的来源与去向，可在设置中修改快捷键。可选的 FIM 补全从当前编辑器发起，并在编辑器内显示请求状态。

### 工程分析与宿主工具

- 导入 filelist 后，实时诊断和 `Ctrl`+点击按该工程的文件集查找定义，保留工作区和用户的 slang 编译设置，且能定位合法 `include` 中的模块定义。未纳入清单的同名文件不会替换工程定义。
- 集成终端和版本控制使用首选项选定的宿主 shell。版本控制从宿主有效 `PATH` 查找 Git 或 Subversion，也可指定绝对路径。缺少 Git 和 SVN 时仍可启动并编辑文件。
- 修复打包应用切换界面语言后重启时的环境恢复，并保留 AppImage 解包运行方式。

### 下载与启动

选择一种格式，并把同版本的 `SHA256SUMS` 放在下载目录。以 AppImage 为例，运行 `awk '$2 == "VEdit-0.4.1-x86_64.AppImage"' SHA256SUMS | sha256sum --check`，确认该文件显示 `OK`。校验其他格式时替换命令中的文件名。

| 下载文件 | 启动方式 |
|---|---|
| `VEdit-0.4.1-x86_64.AppImage` | `chmod +x VEdit-0.4.1-x86_64.AppImage` 后运行。没有 FUSE 时加 `--appimage-extract-and-run` |
| `vedit-0.4.1-linux-x86_64.tar.gz` | `tar -xzf vedit-0.4.1-linux-x86_64.tar.gz`，然后运行 `./vedit-0.4.1-linux-x86_64/AppRun` |
| `VEdit-0.4.1-x86_64.run` | `chmod +x VEdit-0.4.1-x86_64.run` 后运行，或用 `--extract DIR` 解到新目录供后续启动 |

### 已知限制

- CentOS 7 容器检查覆盖 glibc 2.17 用户空间。CentOS 7 原生 3.10 内核需独立验证。桌面交互改动在 X11/Xvfb 下验证，原生 Wayland 和生产 FIM 服务未覆盖。
- 大型工程的索引启动和刷新耗时尚未测量。刚切换文件时，`Ctrl`+点击可能需要等当前文件的语言会话就绪后重试。
- 本轮版本控制端到端测试使用本地 Git 和 SVN 仓库，真实 HTTPS 和 SSH 远端未覆盖。
