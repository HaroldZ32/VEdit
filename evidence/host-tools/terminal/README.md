# Host shell selection and terminal

The host shell is selected in Preferences → Tools. Auto follows an executable supported `$SHELL` and falls back to installed shells. Apply and OK store the selection in `settings.toml` for the next terminal or VCS launch. Cancel leaves the saved choice in place. A saved executable that becomes unavailable gives a diagnostic with a recovery action.
