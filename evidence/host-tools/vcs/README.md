# Git and Subversion through the host shell

The shared Rust host launch code applies process variables, restored host PATH, and the imported global and project overlay. It removes AppDir directories from PATH and rejects AppDir executables, including symlink targets. It strips `LD_LIBRARY_PATH` and `LOCPATH` from the launch environment. Git and SVN search effective PATH before the named fallback variables. Job-specific credential environment entries are applied per process. PTY-specific terminal capability variables are added by the terminal.

VCS jobs and version probes use the saved shell in noninteractive mode. The shell receives the executable and command arguments as separate values. csh and tcsh use a fixed `/bin/sh` trampoline to preserve empty arguments. Interactive PTY startup continues to use the native shell startup behavior.
