The A3 review (evidence/ux-batch-2/review-a3/REPORT.md, Medium 5) recorded that the

Attribution (reported by the lane that owned the code)
------------------------------------------------------

switch in `src/app/editor_area.cpp` (a source file outside A3's write scope). A3 did not chase the crash
and did not modify that file. The attribution is therefore the other lane's, not an A3 finding.

Conclusion
----------
The two SEGFAULT occurrences are attributed to the other lane's dangling-pointer bug, which is fixed;
the rebuilt tree passes the test both directly (`--selfcheck`, 312 PASS / 0 FAIL, exit 0) and through
ctest. The reviewer's Medium 5 can be closed on this evidence. What this note does NOT prove: that the
old crash could never have involved A3 — only that it no longer reproduces on the rebuilt tree and that
the fix was made outside A3's scope.
