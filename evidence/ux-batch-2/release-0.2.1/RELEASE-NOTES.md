# VEdit v0.2.1

真机报障批量修复（19 项）+ 新增**指定顶层模块**。单文件 AppImage，免安装、离线运行（CentOS 7 / glibc 2.17 目标，私有运行时）。

## 新增：指定顶层模块

模块树面板顶部可指定一个顶层模块：`Auto` / 自动检测到的候选顶层 / 手输名字，**按工程根记忆**。指定后**模块树与 lint 都从该顶层出发**。

实测（1176 文件工程、298 MB AST）：Auto 3.99 s（1176 模块 / 1176 个 lint 文件）→ 指定顶层 **0.047 s**（10 模块 / 10 个文件），目录快 26×、lint 约 85×。顶层外的文件**不会被静默丢弃**：摘要行写明 `N file(s) outside the top <名字> are not analysed`，状态点为空心灰（不是绿色）。顶层名字写错会给出具名错误，不会静默回退。

## 修复（每条都有“修前会红”的回归）

**大工程规模**
- 1176 文件工程模块目录空白 / `lint diagnostics exceeded the 268435456 byte limit`：AST-JSON 改流式解析 + 节点预算（进程自身峰值 12.7 MiB）；层级极深的设计按**实测深度**放行，超出则给具名失败，**绝不返回空树**。
- lint 洪泛：流式 + 去重 + 条数上限（40,000 条告警 → 保留 500 条去重结果、丢弃 39,500 并上报、0 失败）。

**工程与跳转**
- 切工程后旧文件堆积、环境不刷新：`[project]` 改为**归属**语义（外层 `vedit.toml` 不再把 filelists/`-I`/`-D` 灌进子目录），切换时 `-I`/`-D` 按新根重钉；新增顶部「切换工程」入口。
- 接口面板 / 模块树**每次**跳转都被拒：slang 的 `source_file` 是相对**它自己的 cwd** 的路径，我们曾按工程根解析 → 丢掉 `rtl/` 段，导致编辑器打开不存在的文件。改在生产者按真实 cwd 解析；同时修正 UTF-8 字节列 → 字符列（目标前有中文时会落偏）。
- 文件名 `0.1.1` / 产品自报 `0.2.0` 的版本割裂：统一为 0.2.1。

**编辑**
- `Ctrl+Z` 把文件变空白：**加载文件本身被记成一步撤销**——改走 `KParts::openUrl`，打开时的文本成为**撤销地板**。
- 快捷键改了不生效/看不见：4 条出厂绑定与 KTextEditor 自有动作撞车（Qt 对相同序列两条都不触发）；注册表成为唯一权威、逐窗格剥离编辑器副本、默认键避开编辑器与桌面全局键、四列表格、显式 `(unbound)`、冲突拒绝并点名属主。
- 手势：`Shift+Alt+拖拽` / `Ctrl+Alt+点击` 成为主手势（`Alt+…` 为次级），`Meta+Alt` 排除；`Ctrl+点击` 仍跳定义。
- 多显示器/主题禁用态不变灰：`QPalette::setColor` 曾把 Active/Inactive/**Disabled** 三组填成同色；30 个主题逐角色断言 + 像素比对。
- `Reset Layout` / `New Empty Layout` / `File→Quit` 静默销毁未保存内容：三条命令现先询问未保存文档。

**诊断与文件**
- 状态点只在“当前聚焦”的文件上出现：判决**算完就丢**；改为**按文件保留**判决（点、面板计数、悬浮框读同一份派生），新增第 4 态“未分析”（空心灰），filelist 文件出现在树内「From filelist (N)」分组并在 Project 面板可见；1176 行列表刷新 3 次而非 1176 次。
- 悬浮框只在左侧 gutter 图标上弹出：鼠标过滤器曾装在公开 `KTextEditor::View` 上，而真实移动投递给内部 `KateViewInternal`；现挂整棵控件树，纯观察者（不抢选区/tooltip/Ctrl+点击）。
- `.f` filelist 被当 HDL 源码解析并报语法错：改为**语言/能力注册表**（`.f` 是工程清单，不是源文件；非源文件是“无可用分析器”状态，不是跳过），加语言只需加一行数据。
- 文件对话框：filelist 扩展名单一来源；选中过滤器在 `show()` 之前显式应用到模型。

**文档**
- 用户手册重写为 Qt6 手册（GTK3 时代内容清除，安装/排障移到附录），键位与手势表由注册表**推导**而非手抄；`README` 与发布检查单改为 Qt6 交付物（此前会引导发布旧 GTK 产品）。

## 仍不宣称

真实桌面 GUI 未逐项驱动（界面证据来自离屏/软件渲染 + 代码核对）；分屏的“双窗格鼠标”用例缺失；**原生（KDE）文件对话框未测**（包内无平台主题插件，交付形态即 Qt 对话框）；FIM 的 Rust 侧错误串仅中文；语法定义 4/5 名字在装有 KDE 定义的环境里被内嵌副本遮蔽（**交付的 AppImage 不受影响**，其语法库只含随包白名单 5 份）。
