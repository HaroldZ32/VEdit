# 实机复验清单（拿到重打包的 AppImage 后照此逐条验）

> 每行 = 你报过的一条现象 → **现在应该看到什么** → 怎么快速验。
> 若某条仍不对，把这行编号 + 现象贴回来即可，我不需要你再描述背景。
> 台账（根因/修法/证据）在 `REAL-MACHINE-FINDINGS.md`。

## 1. 大工程模块目录（RM-1 / U9）

- **原现象**：1176 文件工程报 `slang failed: lint diagnostics exceeded the 268435456 byte limit`，模块树与接口面板**空白**。
- **现在应看到**：模块树出树（1176 模块 / 顶层是"从未被例化"的那些）；**即使 AST 到 GB 级也只是慢，不失败**；若目录被截断，面板摘要会写明原因。
- **验法**：打开那个工程 → 看左侧模块树是否列出模块；把鼠标放到顶层模块上看定义位置是否正确。
- **已知残留**：层级**极深**（>~42 层例化）的设计仍可能拿不到树（U9d 在修，目标是"部分树 + 警告"，绝非空树）。

## 2. 工程切换（RM-2）

- **原现象**：同一窗口切到别的文件夹，文件树堆旧文件、环境（-I/-D/filelist）不刷新。
- **现在应看到**：切到 B 后，文件树**只剩 B**；分析/目录/lint 用的是 B 的 filelist 与 `-I/-D`；B 里看不到 A 的任何路径；**未保存的标签与缓冲区仍在**；**每个工程有各自的变量表**（A→B→A 回来时 A 的变量仍在）。
- **验法**：A→B→A 来回切两次，每次看三点：文件树有没有旧文件、状态栏的工程名、Project 面板的 filelist 列表。
- **新入口**：File 菜单与主工具栏都有「切换工程(&W)…」。

## 3. filelist 与非 HDL 文件（RM-11）

- **原现象**：`filelist` 文件自己被当源码解析，报语法错。
- **现在应看到**：`.f` **零诊断**（它只是工程清单，会被读取）；`.md`/`.tcl`/`.sdc` 等**不会被解析**；filelist 里列出的源码**会**被分析。
- **验法**：打开工程后看诊断里还有没有指向 `.f` 的语法错误。

## 4. 接口面板 / 模块树跳转（RM-4 + RM-4b）

- **原现象**：两个面板的**每一次**双击/Ctrl+双击都报"编辑器拒绝了跳转"。
- **根因（已证实）**：源码在 `rtl/` 这类**子目录**里时，slang 给的相对路径被按工程根解析，丢了子目录段 → 编辑器打不开不存在的文件。
- **现在应看到**：双击端口 → 跳到**声明**；Ctrl+双击 → 跳到**例化语句**；两个面板都正常；目标前有**中文注释**时也能精确落在标识符上（之前会偏几列）。
- **验法**：在 `rtl/` 布局的工程里，对任意端口做两种手势。
- **若仍失败**：把面板/状态栏那一整行贴我（现在会带路径 + workspace root + 真实原因）。

## 5. 撤销（RM-5a）

- **原现象**：Ctrl+Z 几次后文件变空白、再按没反应。
- **根因（已证实）**："打开文件"本身被记成一步撤销；未改过的文件只有这一条，第一次 Ctrl+Z 就把缓冲撤成空。
- **现在应看到**：**打开一个文件、什么都不改、按 Ctrl+Z → 什么都不发生**；连续撤销到"刚打开时的内容"就停住；撤销后仍可正常输入。
- **验法**：上面那句就是最小验证。

## 6. 快捷键（RM-5b + RM-5c）

- **原现象**：快捷键设置"能改但不生效、看不见"；很多命令没默认键。
- **根因（已证实）**：4 条绑定**早就死了**（和 KTextEditor 自带动作撞车，Qt 把两边都不触发）：`Ctrl+Shift+S`/`Ctrl+Shift+H`/`Ctrl+Alt+V`/`Ctrl+P`；且改绑没有属主校验。
- **现在应看到**：设置里快捷键页有 4 列（**生效 / 默认 / 状态**），未绑定显式写 `(unbound)`；**改完立即生效**、重启仍在；冲突会被**拒绝并点名属主**；默认键照 VS Code 且**避开编辑器自有键**，并避开桌面全局键（`Ctrl+Alt+T`→终端、`Ctrl+Alt+D`→显示桌面这类）。
- **验法**：改一条绑定 → 立刻按键试 → 重启再试；再试 `Ctrl+P`（快速打开）是否真的打开。

## 7. 多光标 / 列选择手势（RM-6）

- **原现象**：`Alt+点击/拖拽` 被窗口管理器抢去移动窗口。
- **现在应看到**：主手势是 **`Shift+Alt+拖拽` = 列/块选择**、**`Ctrl+Alt+点击` = 加/减光标**；`Alt` 版本仍保留（WM 没占用时可用）；`Ctrl+点击` 仍是跳定义。
- **验法**：KDE 与 GNOME 各试一次。

## 8. 禁用态不变灰（RM-7 + RM-7b）

- **原现象**：该灰的地方（Lint 引擎=slang 时的 verible 旋钮、撤销按钮）看着和可用的一样。
- **根因（已证实）**：`QPalette::setColor` 把 Active/Inactive/**Disabled** 三组填成同一颜色，代码里从未设过 Disabled 组 → 30 个主题全部"禁用==启用"。
- **现在应看到**：禁用控件的文字明显变灰；"后端不支持（灰+原因）"与"待接线（仍可编辑）"两种状态**仍能区分**。
- **验法**：Lint 页把引擎切到 slang，看 verible 专有旋钮是否变灰；空撤销栈时看工具栏撤销是否变灰。

## 9. 状态点（RM-9）

- **原现象**：只有**当前聚焦**的文件有点，其它文件没有；filelist 文件没地方显示。
- **根因（两条）**：判决**算完就丢**（切标签即失忆）+ 分析侧路径被 RM-4 那个 bug 打歪。
- **现在应看到**：**绿/黄/红**覆盖整个工程集；**切走再切回，点还在**；新增第 4 态**空心灰环 = 未分析/被排除**（脏缓冲区）；filelist-only 文件出现在树的 **「From filelist (N)」** 分组里且**带点**，Project 面板 Files 列表也有标记。
- **验法**：开两个文件，来回切，看两边的点是否都在；再看 tree 底部有没有 filelist 分组。

## 10. 悬浮框（RM-10）

- **原现象**：只有左侧 gutter 图标能弹，**划线的文字上不弹**。
- **现在应看到**：鼠标落在**波浪线覆盖的文字**上就弹（含多行诊断的每一行）；弹窗不挡住光标下的文字；分屏下跟随鼠标所在窗格。
- **验法**：把鼠标放在任意一条红/黄波浪线上（不是左侧图标）。

## 11. 进程内环境变量对话框（RM-3）

- **原现象**：对话框只能改已有值，**不能加、不能删**。
- **现在应看到**：可以**新增变量名+值**、每行可**删除**；名字有内联校验（空/重复/非法字符）；删掉一个"工程仍然需要"的变量时，它会变成"缺失"并再次提示，**不会静默消失**；变量**按工程根保存**（切走再回来仍在）。
- **验法**：加一个变量 → 存 → 重启 → 切到别的工程 → 切回来。

## 12. 重置布局 / 退出（RM-12）

- **原现象**：`Reset Layout`、`New Empty Layout` 静默销毁未保存内容（你已实测确认）。
- **现在应看到**：两条命令**先问未保存确认**（Save All / Discard All / Cancel），**取消则一切原样保留**；干净状态不弹窗、照样瞬间重置；**`File → Quit / Ctrl+Q` 也会先问**。
- **验法**：改一个文件不存 → 按 `Ctrl+Alt+R` → 应弹确认 → 点取消 → 内容与布局都在。

## 13. 帮助里的用户手册（RM-8 + RM-8b）

- **原现象**：手册是 GTK3 时代的混合文档，先讲安装和源码构建。
- **现在应看到**：打开 F1 就是**界面总览 → 打开/切换工程 → 编辑 → 搜索 → 模块树/接口 → 诊断 → 导航 → 设置 → 语言 → 已知限制**；安装/部署/排障/配置位置在**附录**；键位表与手势表是**新默认**（含 `(unbound)` 与偏离说明）。
- **验法**：F1，先看目录。

## 14. 中文输入（RM-13，未修，已披露）

- 包内缺 Qt 的 `platforminputcontexts` 插件、AppRun 收窄了 `QT_PLUGIN_PATH`，有 ibus/fcitx 的机器上可能加载不到（你的环境没有中文输入法，所以不受影响）。手册 §9.2 已写明。
