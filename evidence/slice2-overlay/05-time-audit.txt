## 8. one literal-grep false positive, explained
A naive grep for the OLD window's tail can hit unrelated digits in a backfill timestamp: 07-binding.txt
records the wall-clock time at which that note was written (a PAST time), and its minute:second digits
happen to contain the same digit pair as the old window's tail. Section 2/4 use boundary lookarounds AND
resolve every token against 'now', which is why they report 0 future tokens; the naive literal grep in
this spot is a substring artefact, not a future time. No file in this directory carries a time later
than audit_time above.
