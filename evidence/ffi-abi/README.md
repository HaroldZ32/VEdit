# ffi-seam evidence — T4 / Slice 0 (Rust service layer + C ABI)

Frozen contract: `.mpd/cellwork/cell-20261031T085543161Z/contracts/ffi-seam.md`.
Every file is raw tool output; `00-collect.txt` carries the C9 stamp (collection
time, `git rev-parse HEAD`, `git status --porcelain`) for the whole directory.

## The deliverable

* `crates/vd-ffi` — the C ABI crate: `staticlib` + `rlib`, the only crate that
  may contain `unsafe`, header generated by cbindgen from the `extern "C"`
  surface (`cbindgen.toml` + `build.rs` → `include/vd_ffi.h`).
* `crates/vd-search`, `crates/vd-settings`, `crates/vd-vcs` — the search/VCS/
  settings backends behind the ABI (real minimal services, unit-tested).
* `cmake/VEditRustFfi.cmake`, root `CMakeLists.txt`, `src/app/CMakeLists.txt` —
  the imported `vd_ffi` target, linked into `vedit-app`; missing library =
  configure failure, never a silent skip.
* `scripts/build-qt.sh`, `scripts/build-qt-in-container.sh` — the Rust stage
  (build, unit tests, `cargo tree` isolation, header guard) and the container
  configure that links the library and asserts the exported symbols.
* `src/app/main.cpp` — `--selfcheck-ffi <project-dir>`: the C++ caller of the C
  ABI (also a ctest entry: `vedit-app-ffi-abi-selftest`).

## The seven services (AC-0.2) and their entries

| # | service | C entry points | backend |
|---|---|---|---|
| 1 | project model + `.f` | `vd_project_parse` / `vd_project_poll` / `vd_project_info_free` | `vd-config` |
| 2 | Verible LSP | `vd_lsp_start` / `vd_lsp_poll` / `vd_lsp_info_free` | `vd-lsp` |
| 3 | SLANG deep lint | `vd_deeplint_lint` / `vd_deeplint_poll` / `vd_diagnostics_free` | `vd-deeplint` |
| 4 | FIM | `vd_fim_complete` / `vd_fim_poll` / `vd_fim_result_free` | `vd-fim` |
| 5 | search index | `vd_search_query` / `vd_search_poll` / `vd_search_results_free` | `vd-search` |
| 6 | VCS backend | `vd_vcs_status` / `vd_vcs_poll` / `vd_vcs_status_free` | `vd-vcs` |
| 7 | settings store | `vd_settings_load` / `vd_settings_save` / `vd_settings_poll` / `vd_settings_free` | `vd-settings` |

Common: `vd_abi_version`, `vd_service_create`, `vd_service_destroy`,
`vd_service_error`, `vd_job_cancel`, `vd_job_release`. Every entry returns a
`uint64_t` job id and never blocks; the caller polls (C2).
