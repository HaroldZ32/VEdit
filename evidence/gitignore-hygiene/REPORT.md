## 3. Where the dispatch's assumptions did not match the repository

1. **`samples/` is not generated.** `build-tarball.sh:56` copies
   `"$OUT/samples"` **into** the tarball, `verify-centos7.sh:22` uses
   `samples/verilog-demo` as its input, and `STEPS.md:103` documents it. There is
   no generator. It is the authored sample project (`top.v`, `counter.v`,
   `bad.v`, `demo.f`, ~1.4 KB) and must be **committed**, not ignored.
2. **`build/glibc217-spike/` holds no products**, so it needs no ignore rule; its
   `run-spike.sh` is a source script and should be committed.
3. `build/centos7-verify/dist/` also needed a rule because the `.sha256` sidecar
   was not covered by the global `*.tar.gz` pattern (the tarball itself was).

Consequence for the acceptance bullet: `git check-ignore -v build/glibc217-spike`
does **not** match, and neither does `.../samples` — deliberately, because both
are sources. The three generated directories do match (evidence 01).
