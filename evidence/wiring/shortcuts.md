| action | shortcut | description |
|---|---|---|
| `open` | <Ctrl>o | open a file in a new tab |
| `new` | <Ctrl>n | new untitled tab |
| `save` | <Ctrl>s | save the current tab |
| `save-as` | <Ctrl><Shift>s | save the current tab under a new path |
| `close-tab` | <Ctrl>w | close the tab (confirms unsaved changes) |
| `quit` | <Ctrl>q | quit the editor |
| `undo` | <Ctrl>z | undo the last edit (native GtkSource undo) |
| `redo` | <Ctrl><Shift>z | redo |
| `find` | <Ctrl>f | show the find bar |
| `replace` | <Ctrl>h | show the replace bar |
| `find-next` | F3 | jump to the next match |
| `goto-line` | <Ctrl>g | jump to a line |
| `format` | <Ctrl><Shift>f | one-key format through the LSP, one undo step |
| `slang` | <Ctrl><Shift>l | run SLANG deep lint into the problem panel |
| `definition` | F12 | jump to the definition (LSP) |
| `references` | <Shift>F12 | list references (LSP) |
| `outline` | <Ctrl><Shift>o | document symbols of the current file |
| `rename` | F2 | preview the LSP rename edits (nothing is applied) |
| `fim` | <Alt>backslash | request an FIM completion as ghost text |
| `toggle-panel` | <Ctrl><Shift>p | show/hide the problem panel |
| `accept-fim` | Tab | insert the pending FIM completion through Document |
| `cancel-fim` | Esc | discard the pending completion / cancel the request |
