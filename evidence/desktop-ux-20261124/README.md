# VEdit 桌面体验验收

本轮验证使用固定版本 Rust、Qt 6、KTextEditor 及独立状态目录。桌面交互在 X11/Xvfb 下运行，AppImage 使用 `APPIMAGE_EXTRACT_AND_RUN=1` 启动。最终包 `VEdit-0.4.0-desktop-ux-x86_64.AppImage` 的 SHA-256 为 `9e64d89f18aa3ff1573ea91fd27b0c5b3dc6ca33800e78da100cc47c81306135`。

| 检查 | 观测结果 |
|---|---|
| 驱动、负载和两种链快捷键 | F7、F9、Shift+F7、Shift+F9 从编辑器焦点触发，修改绑定后重启生效。 |
| 树表列宽 | 拖动追踪、模块树和接口表的表头分界线后，结果刷新或重新打开仍保留宽度。 |
| 分隔条 | 两种主题下实测窗格间隙 5 px、编辑分屏手柄 4 px，两个方向都能拖动。 |
| 窗格顶端按钮 | 主窗口和文件树移除按钮行，原操作仍可从菜单或快捷键到达。 |
| 全部展开和折叠 | 一次展开到达第 520 个同级目录及其子目录，跳过目录符号链接，编辑器仍只有原先的标签。 |
| 文件夹与独立文件 | 单独打开文件时没有工程根，最近文件夹可重开，空启动遵循恢复选项；切换目录保留未保存缓冲区。 |
| 搜索历史 | 搜索窗格与查找替换框共用最近 20 条已提交的查询，去重并在重启后可用。 |
| 侧面搜索 | 左、右、底部停靠均可操作。独立文件搜索 `beta` 跳到 3:8，同目录和工作目录的对照词未命中。[最终包搜索记录](standalone-search.log) |
| filelist 路径补全 | 在 `.f` 内输入相对路径，选择目录再选择文件，回车补成 `../rtl/board.sv`。显式保存后才写入文件。 |
| Markdown | 打开 `.md` 和 `.markdown` 实测标题、强调、链接和代码样式。 |
| FIM | 已打开的编辑器应用设置后，用手动快捷键或右键请求本地测试服务，Esc 放弃、Tab 插入一次。未配置及失败时编辑器显示原因。 |
| HDL 高亮 | 在浅色与深色主题中实测定义名、例化名、条件关键字、块关键字和括号。注释、字符串及原生折叠正常。 |
| 开屏置顶 | X11 下开屏覆盖竞争窗口，主窗口首次绘制后开屏关闭，主窗口保持普通层级。 |
| 追踪链 | 真实 slang 工程验证两种追踪方向，每跳显示源信号和目标信号，能区分分支、环和深度限制。 |

`bash scripts/build-qt.sh` 完成构建，默认配置 91 项通过、2 项 SVN 测试跳过。提供 SVN 工具后全部 93 项通过。`bash scripts/gates.sh` 验证 Rust 工作区，850 项通过，4 项规模测试忽略。最终手册重链接后另验 F1 正文、打包清单和独立文件搜索。[Qt 默认结果](qt-canonical-counts.log) · [Qt 完整结果](qt-provisioned-counts.log) · [Rust 结果](rust-counts.log)

替换为另一套 Slang LSP 配置时，诊断提示文字和跨文件重命名两项在本次及此前版本上均可复现失败。FIM 采用本地可控服务；桌面置顶实测覆盖 X11。原生 Wayland 及生产 FIM 账号未测。
